# CommuteChoice (자차 vs 대중교통 총비용 비교)

생활패턴(출퇴근 횟수, 거리, 시간)을 입력하면 자차/대중교통의 총비용(TCO)과 손익분기점을 계산합니다.

## 실행 방법
- 이 프로젝트는 정적 웹앱입니다.
- `index.html` 파일을 브라우저로 열면 실행됩니다.

## 주요 기능
- 1~10년 누적 비용 비교 (자차 vs 대중교통)
- 손익분기점(교차 시점) 계산
- 시간 가치(기회비용) 반영 토글
- 연도별 연간/누적 비용 표 출력

## 폴더 구조
- `index.html` : UI
- `styles.css` : 스타일
- `calc.js` : 계산 로직 모듈
- `validate.js` : 입력 검증(엣지케이스)
- `app.js` : 이벤트/렌더링
