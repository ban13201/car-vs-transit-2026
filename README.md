# CommuteChoice (자차 vs 대중교통 총비용 비교)

생활패턴(출퇴근 횟수, 거리, 시간)을 입력하면 자차/대중교통의 총비용(TCO)과 손익분기점을 계산합니다.

출퇴근 패턴(거리, 횟수, 시간)을 입력하면  
자차와 대중교통의 총소유비용(TCO)과 손익분기점을 계산하는  
의사결정 지원 웹 애플리케이션입니다.

##  주요 기능

- 자차 총소유비용(TCO) 계산
  - 차량 가격
  - 감가상각
  - 연료비
  - 보험·정비비
- 대중교통 총비용 계산
- 시간 가치(Time Value) 반영 ON/OFF
- N년 누적 비용 비교
- 손익분기점(Breakeven) 계산

---

##  계산 모델 개요

### 자차 총비용

TCO = 초기구매비 + 감가상각 + 연료비 + 유지비 + (시간가치)

### 대중교통 총비용

Total = 교통비 × 이용횟수 × 기간 + (시간가치)

시간 가치는 사용자가 ON/OFF 선택 가능하도록 설계하였습니다.
